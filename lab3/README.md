# Лабораторна робота №3 (ІКТ) — Python замість Excel

Виконавець: **Колеснік**, варіант `k = 7`.

Лабораторна робота №3 з курсу «Інформаційні і комунікаційні технології» (ЛНУ ім. Івана Франка, економічний факультет), виконана мовою Python. Розрахунки, таблиці, графік і перевірки ті самі, що й в оригіналі в MS Excel.

## Встановлення та запуск

```bash
cd lab3
pip install -r requirements.txt

python main.py                         # k = 7, прізвище «Колеснік»
python main.py --k 11                  # інший варіант: усе перераховується
python main.py --k 7 --surname Колеснік --output output

pytest                                 # тести
```

Потрібен Python 3.10 або новіший.

## Результати для k = 7

**3.1.** Вартість у таблиці 1: 170, 1200, 85, 255, 210, 1140, 405, 680.
- Таблиця 7 (М1 **І** Т1): 3 рядки, бази Б1, Б3, Б4.
- Таблиця 8 (Т1 **АБО** Т4): 6 рядків.
- Таблиця 9: М1, М2.

**3.2.** Попит `P = 7000/Q`, пропозиція `P = e^(Q/10)`.
- Рівноважний випуск `Q* = 49.5141`, ціна рівноваги `P* = 141.37`, різниця `P1 − P2 ≈ 1e-12`.
- `brentq`, `fsolve` і власна бісекція дають однаковий результат.
- Криві перетинаються між `Q = 45` і `Q = 50`, саме там, де на графіку видно точку перетину. Отже, числовий розв'язок збігається з графічним.

**3.3.** Система `A·x = b`, де `A = [[5,1,-1],[1,4,2],[2,-3,3]]`, `b = [38, 67, 23]`.
- `Δ = 102`, `Δ1 = 822`, `Δ2 = 924`, `Δ3 = 1158`.
- `x1 = 8.0588`, `x2 = 9.0588`, `x3 = 11.3529`. Обидва методи та `numpy.linalg.solve` дають однаковий розв'язок, а `A·x = b` виконується.

Систему з методички можна підставити так: `task_3_3_linear.run(k, A=MANUAL_A, b=manual_b(k))`.

## Відповідність інструментам Excel

| Excel | Python |
|---|---|
| Розширений фільтр (умови в одному рядку = І, у різних рядках = АБО) | булеві маски `pandas`: `&`, `\|` (також `df.query(...)`) |

## Тести

`pytest` перевіряє всі значення для `k = 7` з умови завдання. Для інших `k` (1, 3, 11, 25) очікувані результати рахуються незалежно, через `numpy.linalg.solve` і `scipy.optimize.brentq`. Ще один тест запускає `main.py` для `k = 7` і `k = 11` та перевіряє, що всі файли створено.
